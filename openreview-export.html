利用已经能显示论文列表的 OpenReview 正常浏览器会话，直接从官方 API 导出 ICLR 2027 的公开活跃投稿。此页面仅提供脚本；数据请求在你的 OpenReview 页面运行。

  1. 点击下方“复制导出脚本”。
  2. 切回能看到论文列表的 OpenReview 官方页面，按 F12 打开开发者工具，选择 Console／控制台。
  3. 粘贴脚本并按 Enter，保持该页打开，等待下载 iclr-2027-official-active-submissions.json。下载完成后告诉我。

脚本只对 OpenReview 官方 API 发出读取请求，逐页检查投稿总数、唯一 ID、活跃状态和公开字段。不读取或导出账号密码、Cookie、令牌、私有评论或作者身份字段。遇到验证或分页错误时停止，不下载残缺文件。

下载六篇代表论文的官方原稿

完整投稿 JSON 已导入后，可以继续取得 Softmax Reparameterization、Chameleon、HeadGuard、QuantMLA、JustQuant 和 AYOT 的投稿 PDF，用于核对正文、表格与附录。

  1. 点击“复制官方 PDF 脚本”，在同一个正常 OpenReview 官方页面的 Console 粘贴执行。
  2. 等待下载 iclr-2027-six-official-papers.zip，把文件放到当前项目根目录。

脚本先核对六篇官方 ID、公开权限、活跃状态和原稿路径，再从官网逐篇下载，生成含文件校验值的 ZIP。它不提取账号或会话信息；任何一篇遇到验证、版本变化或返回非 PDF 内容时停止，不生成残缺压缩包。
