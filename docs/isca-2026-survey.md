### 逐篇解读的证据边界

该官网议程只提供论文标题、作者及日程，没有论文摘要、PDF 或 DOI。索引中 `abstract` 与 `paper_url` 保持 `null`；官方场次链接放在 `source_url`。不根据标题编造摘要、实验指标或论文下载地址。

另外维护的中文论文笔记按**完全相同的官方标题**与索引连接。每篇记录解读所依据的材料、原始来源链接及证据范围：公开摘要解读只报告摘要支持的内容；公开原文解读记录实际核对的原文章节。本次 6 篇公开原文解读依据各卡片注明的选定章节，不表示整篇论文已完整阅读。题目导读只能说明可能的阅读重点。作者报告的结果与独立复现必须区分。跨论文观点和选题建议属于调研者的综合判断，不能写成全会议共识。

### 重建与更新

仓库中的同步脚本 `scripts/sync_isca2026.py` 仅依赖 Python 3 标准库。更新官网快照：

~~~bash
python3 scripts/sync_isca2026.py
~~~

按已保存的同一快照离线重建：

~~~bash
python3 scripts/sync_isca2026.py --input-html assets/data/isca-2026-source.html
~~~

离线重建仅在原始 HTML 的 SHA256 与已有索引一致时继承原采集时间。首次导入新的官方 HTML 时需要传入真实采集时刻，例如：

~~~bash
python3 scripts/sync_isca2026.py --input-html assets/data/isca-2026-source.html --fetched-at 2026-10-09T09:13:49Z
~~~

脚本检查：每个 `.paper` 节点均被索引或明确记录为空白占位；场次 ID 与官方锚点一致；标题、作者与场次不缺失；论文 ID 和场次 ID 唯一；Industry Track 与官方场次标题一致。新增场次必须先显式更新分类映射。若官网开始提供论文链接，脚本会停止并要求检查链接语义，避免把非论文链接误当作原文。

所有解析和完整性检查成功后才替换索引。重新生成数据后，应核对页面计数、每篇笔记与当前官方标题的匹配关系、来源链接、解读材料和实际阅读章节；人工笔记不能自动继承为新版本的原文阅读证据。
